# create-pull-request

Proxy for [peter-evans/create-pull-request](https://github.com/peter-evans/create-pull-request), pinned to a commit SHA. Creates or updates a pull request for changes made in the workflow.

All inputs and outputs are forwarded unchanged; see the upstream documentation for details.

## Usage

```yaml
- uses: techcode-io/github-actions/create-pull-request@create-pull-request/v1
```
